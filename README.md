# Simple Interest Calculator

A simple Bash script that calculates simple interest based on the principal amount, annual interest rate, and time period in years.

## Formula

```text
Simple Interest = (Principal × Rate × Time) / 100
```

## Inputs

* `p` — Principal amount
* `t` — Time period in years
* `r` — Annual rate of interest

## Output

The script calculates and displays the simple interest.

## Usage

Run the script using Bash:

```bash
bash simple-interest.sh
```

The script will prompt you to enter the principal amount, time period, and annual interest rate.
